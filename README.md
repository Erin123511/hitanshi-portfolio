# Hitanshi | Portfolio

A modern, animated single-page portfolio for Hitanshi, an MCA student.

- Plain HTML, CSS and JavaScript, no build step
- Three.js particle hero (loaded from CDN)
- Scroll-triggered animations, typed headline, animated counters and skill bars
- Placeholder images from [picsum.photos](https://picsum.photos)
- Palette: `#7C5CFF`, `#22D3EE`, `#F472B6` on `#0B1020`

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Deploy

Deployed as a Render static site (publish directory `./`, no build command).
